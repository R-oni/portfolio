Pipeline ETL e Análise Preditiva de Dados Financeiros

2025 – 2026
Python Pandas NumPy SciPy SQL Matplotlib Jupyter Notebook
Pipeline ETL em Python para ingestão e transformação de dados financeiros de múltiplas fontes (CSV, API REST, Excel) com detecção automática de anomalias. Regressão e séries temporais para projeção de receita, documentados em Jupyter Notebooks reproduzíveis no GitHub.
Configuração

Crie um repositório público no GitHub chamado etl-financial-analysis. Clone localmente e configure o ambiente.

2 Definir e obter as fontes de dados
O projeto usa três fontes propositalmente diferentes para reforçar o ETL de múltiplas origens:
  • CSV — Dataset financeiro público: Kaggle "Personal Finance" ou gere dados sintéticos com Faker
  • API REST — Cotações históricas via Alpha Vantage (grátis) ou yfinance
  • Excel — Planilha de orçamento: crie manualmente 1 aba com colunas Mês, Receita, Despesa, Categoria

Transformação (T) + Anomalias
4 Notebook 2 — Transformação e detecção de anomalias
Crie 02_transform.ipynb. Limpe, normalize tipos e aplique o detector de anomalias com Z-score (SciPy). 
from scipy import stats
import numpy as np

# Leitura
df = pd.read_parquet("data/raw/finance_csv.parquet")

# Padroniza datas e tipos
df["date"] = pd.to_datetime(df["date"])
df["amount"] = df["amount"].astype("float64")

# Detecta anomalias pelo Z-score
z_scores = np.abs(stats.zscore(df["amount"]))
df["anomalia"] = z_scores > 3          # True = outlier

# Salva
df.to_parquet("data/processed/finance_clean.parquet")
Atenção: Coloque células print(df.dtypes) e df.head() entre as etapas — o recrutador lê o notebook e precisa ver o raciocínio.
Análise Preditiva
5 Notebook 3 — Regressão Linear (projeção de receita)
Crie 03_predict_regression.ipynb. Regressão linear simples para prever receita futura. 
from scipy.stats import linregress
import matplotlib.pyplot as plt

df = pd.read_parquet("data/processed/finance_clean.parquet")

# Converte data para número (dias desde o início)
df["t"] = (df["date"] - df["date"].min()).dt.days
receita = df[df["categoria"] == "receita"]

slope, intercept, r, p, se = linregress(receita["t"], receita["amount"])

# Projeta próximos 90 dias
t_futuro = np.arange(receita["t"].max(), receita["t"].max() + 91)
projecao  = intercept + slope * t_futuro

plt.figure(figsize=(10, 4))
plt.plot(receita["t"], receita["amount"], label="Real")
plt.plot(t_futuro, projecao, "--", label="Projeção", color="orange")
plt.legend(); plt.title("Projeção de Receita — Regressão Linear")
plt.tight_layout(); plt.savefig("outputs/projecao_receita.png", dpi=150)
6 Notebook 4 — Série Temporal com média móvel
Crie 04_timeseries.ipynb. Suavize a série com média móvel e adicione banda de desvio padrão. 
# Agrega por mês
mensal = df.resample("ME", on="date")["amount"].sum()

mm3  = mensal.rolling(3).mean()  # média móvel 3 meses
std3 = mensal.rolling(3).std()

fig, ax = plt.subplots(figsize=(10, 4))
ax.plot(mensal, label="Mensal", alpha=0.5)
ax.plot(mm3, label="MM-3", linewidth=2)
ax.fill_between(mm3.index, mm3 - std3, mm3 + std3, alpha=0.15, color="blue")
ax.set_title("Série Temporal — Receita Mensal")
ax.legend(); plt.tight_layout()
plt.savefig("outputs/serie_temporal.png", dpi=150)

Dashboard de RH e People Analytics

2026
Power BI DAX Power Query Excel Tableau SQL
Painel de People Analytics no Power BI com métricas de turnover, absenteísmo e headcount a partir de dataset de RH público. Segmentação por departamento e senioridade com filtros cruzados. Versão replicada no Tableau publicada no Tableau Public e GitHub.
Dataset e Preparação
1 Baixar o dataset de RH público
Use o dataset IBM HR Analytics Employee Attrition & Performance do Kaggle — é o dataset de RH mais citado, público, sem dados reais de pessoas e com todas as colunas necessárias (turnover, departamento, senioridade, absenteísmo).
IBM HR Analytics (Kaggle) Download direto CSV (GitHub IBM)
Cite no README: "Dataset: IBM HR Analytics Employee Attrition & Performance — Kaggle / IBM (domínio público)". Isso elimina qualquer dúvida sobre origem dos dados.
2 Explorar e preparar no Excel (opcional mas recomendado)
Abra o CSV no Excel, revise os tipos de coluna e crie uma aba auxiliar com uma tabela de senioridade mapeando JobLevel (1–5) para Júnior / Pleno / Sênior / Especialista / Gestor. Salve como .xlsx — você vai importar direto no Power BI.
Power BI — Modelagem
3 Importar e transformar no Power Query
No Power BI Desktop, vá em Obter Dados → Excel/CSV. No Power Query:
  • Renomeie as colunas para português (ex.: Attrition → Saiu, Department → Departamento)
  • Substitua valores em Attrition: Yes → 1, No → 0
  • Crie coluna condicional Senioridade baseada em JobLevel
  • Feche e aplique
4 Criar as medidas DAX principais
Na aba Ferramentas de tabela → Nova medida, crie as três métricas do currículo: 
// Headcount
Headcount = COUNTROWS('HR')

// Taxa de Turnover (%)
Turnover % = DIVIDE(
    CALCULATE(COUNTROWS('HR'), 'HR'[Saiu] = 1),
    [Headcount],
    0
) * 100

// Absenteísmo médio (dias)
Absenteísmo Médio = AVERAGE('HR'[AbsenceHours])
// Se o dataset não tiver AbsenceHours, use:
// AVERAGE('HR'[NumCompaniesWorked]) como proxy
Dica DAX: Crie uma tabela de datas com CALENDARAUTO() e relacione com a coluna de admissão para habilitar filtro temporal.
Power BI — Visualizações
5 Montar a página de visão geral + filtros cruzados
Crie a página "Visão Geral" com estes visuais:
  • Cartões KPI: Headcount · Turnover % · Absenteísmo Médio
  • Gráfico de barras: Turnover % por Departamento
  • Gráfico de colunas: Headcount por Senioridade
  • Segmentadores (Slicers): Departamento + Senioridade (no topo da página)
Selecione cada visual, vá em Formatar → Editar interações e confirme que os slicers filtram todos os outros visuais.
Visual extra (diferencial): Adicione um gráfico de dispersão com Satisfação no Trabalho vs Turnover — mostra que você explora correlações.
6 Exportar o .pbix e tirar prints para o GitHub
Salve o arquivo como hr-people-analytics.pbix. Tire prints das páginas (Windows: Win + Shift + S) e salve em outputs/. O .pbix deve estar na raiz do repositório.
Limitação: Power BI não tem publicação gratuita para web — o link do portfólio será o print + o arquivo .pbix no GitHub. Já o Tableau tem publicação gratuita (próximo passo).
Tableau Public
7 Replicar no Tableau Public
Baixe o Tableau Public (grátis), conecte ao mesmo CSV:

  • Crie uma planilha Headcount por Senioridade (mapa de calor ou colunas)
  • Monte um Dashboard combinando as duas planilhas com filtro de ação (Dashboard → Ações → Filtro)
